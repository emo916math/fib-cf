This project contains supplementary material related to the author's paper ``Two-point Padé Approximation'':

- The paper itself (`ODorney_TwoPoint_Fibonacci.pdf` and `.tex`)
- A Lean formalization of the main result and the Exercises that generalize it (`Lean/`)
- A set of Python routines for demonstrating cases of the continued fraction decompositions found in the paper and exploring them further (`cf_explorer/`)
  - *Warning:* the documentation for `cf_explorer` is autogenerated and not guaranteed to be correct or comprehensible.
